What this project does

Turns raw logs into insights

This system collects logs from services and files, stores them centrally, surfaces analytics, flags anomalies, groups related failures, and triggers alerts.

Quick Start

  1. Go to Analytics to view trends and anomalies.
  2. Use Logs to inspect records and find similar logs.
  3. Open Alerts to review triggered incidents.

Core Capabilities

  • Single, bulk, and file-based log ingestion
  • Search, filtering, pagination, and log drill-down
  • Counts, timelines, anomaly detection, and clustering
  • Semantic search and similar-log exploration
  • Threshold and anomaly-driven alerts with scheduler support
